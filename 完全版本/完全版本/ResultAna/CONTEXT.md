# ResultAna 轨迹合规分析

本上下文统一描述仿真轨迹相对 OpenDRIVE 车道边界的定位与合规判定术语。

## Language

**EGO 轨迹记录**：
一次仿真运行中的完整自车轨迹，包含场景 JSON 原文件名和按顺序采样的车辆参考点。
_Avoid_：NPC 路径、规划路径

**场景配置起点**：
场景为 EGO 定义的初始位置，独立于 EGO 轨迹记录中的首个采样点。
_Avoid_：轨迹起点、P0

**目标终点**：
场景为 EGO 定义的预期到达位置，独立于 EGO 轨迹记录中的最后一个采样点。
_Avoid_：轨迹末点、最后记录点

**场景原文件**：
文件名与 EGO 轨迹记录中 `jsonname` 完全一致、从 `D:\Desktop\变异存档\Random` 递归找到的场景 JSON；不得通过删改文件名推导替代文件。
_Avoid_：基础场景、改名场景

**关联道路文件**：
与场景原文件中 `map.name` 完全同名的 XODR。优先使用场景原文件同目录下的变异 XODR；仅当同目录不存在时，才从配置的 OpenDRIVE 地图目录精确查找，不得通过删除随机变异后缀改用基础地图。
_Avoid_：按场景名前缀匹配、自动剥离变异后缀

**车辆半宽**：
从车辆参考点到左右车身外缘的横向距离，当前固定为 `0.95 m`，即车辆宽度 `1.9 m` 的一半。

**越线点**：
车辆参考点到其所在车道任一边缘线的距离严格小于车辆半宽时的轨迹采样点。
_Avoid_：仅中心点越界

**左侧越线点**：
以 EGO 实际行驶方向为基准，车辆左侧外缘越过所在车道左侧边缘线的越线点。
_Avoid_：OpenDRIVE 参考线左侧越线

**右侧越线点**：
以 EGO 实际行驶方向为基准，车辆右侧外缘越过所在车道右侧边缘线的越线点。
_Avoid_：OpenDRIVE 参考线右侧越线

**纵向滑坡事件**：
EGO 在上坡或下坡路面的任意行驶阶段，沿坡面向下发生的非预期纵向持续位移。当前仅在两类强证据下判定：车头朝上坡方向但实际位移持续朝下坡方向；或车辆在坡道上已接近停止，随后重新沿下坡方向移动或加速。默认要求绝对坡度不小于 `1%`、接近停止速度不大于 `0.3 m/s`，并且连续至少 `3` 个路径点沿道路坡面累计向下移动不小于 `0.5 m`；这里的累计位移是道路表面上的纵向距离，不是垂直高度差。不得仅依据 `sim_result` 判定。
_Avoid_：横向侧滑、无法与正常行驶区分的朝下坡方向向前行驶

**跌出路面事件**：
EGO 跌离可行驶路面后进入近似自由加速状态；轨迹记录中任意一个采样点的速度大于 `50 m/s`，即判定发生跌出路面事件，不要求连续多个超阈值点。以轨迹速度为主要判据，不依赖 `sim_result` 的文本结果。
_Avoid_：普通驶出车道、仅凭仿真结果判定跌落

**碰撞候选事件**：
当 `sim_result` 表示发生碰撞时，将整次运行标记为需要人工复核的碰撞候选事件。由于仿真通常会在碰撞后停止，可将最后一个路径点显示为疑似碰撞终点，但不得自动认定为精确碰撞点，也不得从现有轨迹推断碰撞对象、方向或责任。
_Avoid_：已自动确认的碰撞点、自动事故定责

**碰撞复核结果**：
人工对碰撞候选事件给出的结论，取值为“未复核”“确认碰撞”或“排除碰撞”，并可附带人工备注。复核结果和备注属于导出 Excel 工作簿的运行明细中必须保留的审计信息。
_Avoid_：自动碰撞结论

**车辆停滞事件**：
当 `sim_result` 表示 `vehicle stuck` 时记录的运行级异常。现有轨迹不足以自动确定停滞原因和精确发生点，因此只能将最后一个采样点称为“停滞时最后记录点”。
_Avoid_：自动停滞原因、已确认的停滞点

**停滞时最后记录点**：
车辆停滞事件中轨迹记录的最后一个可用采样点，用于表示数据停止记录时的车辆位置，不代表精确的停滞发生位置。
_Avoid_：停滞位置、精确停滞点

**违规触发次数**：
同一违规类型在一个分析批次内形成的独立事件数量；连续路径点组成的同一事件段只计一次，碰撞候选和车辆停滞则在每条 EGO 轨迹记录中最多各计一次。
_Avoid_：违规路径点数

**违规触发场景数**：
一个分析批次内至少触发一次指定违规类型的 EGO 轨迹记录数量；同一记录重复触发该类型仍只计一个场景，触发场景占比以批次内全部 EGO 轨迹记录数为分母。
_Avoid_：违规触发次数、场景文件去重数
